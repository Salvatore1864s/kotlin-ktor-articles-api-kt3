# API для работы со статьями

Учебный проект на Kotlin с использованием фреймворка Ktor. Создан в рамках контрольной точки КТ1 «Базовое API» по предмету «Кроссплатформенная разработка на языке Kotlin».

## Возможности

- Получение списка статей (`GET /articles`).
- Сортировка статей через query-параметр `sort`: `old` или `new`.
- Получение статьи по ID (`GET /articles/{id}`).
- Создание статьи (`POST /articles`).
- Удаление статьи (`DELETE /articles/{id}`).
- Обработк# КТ3 — API с документацией и тестами

REST API на Kotlin с использованием Ktor, PostgreSQL и JWT.

## Возможности

- CRUD для статей: создание, получение, изменение и удаление.
- Регистрация пользователей и вход.
- Хеширование паролей с помощью BCrypt.
- Авторизация с использованием JWT.
- Документация API через Swagger UI и OpenAPI.
- Централизованная обработка ошибок через StatusPages.
- Логирование HTTP-запросов.
- Автоматические тесты через Ktor Test Engine.

## Запуск проекта

1. Установить JDK 21 и PostgreSQL.
2. Создать базу данных `ktor_app` и пользователя `ktor_user`.
3. Проверить настройки подключения в `DatabaseFactory.kt`.
4. Запустить сервер:

```bash
./gradlew run
```

Сервер будет доступен по адресу `http://localhost:8080`.

## Документация API

После запуска открыть:

`http://localhost:8080/swagger`

В Swagger доступны маршруты статей и авторизации.

## Запуск тестов

Выполнить команду:

```bash
./gradlew test
```

Для сборки проекта без запуска тестов:

```bash
./gradlew build -x test
```

## Авторизация

Для создания, изменения и удаления статей требуется JWT-токен. Сначала нужно зарегистрироваться через `/auth/register`, затем войти через `/auth/login` и использовать полученный токен в заголовке:

`Authorization: Bearer TOKEN`
а параметров запроса и формирование JSON-ответов.
- Обработка ошибок с соответствующими HTTP-статусами.

## Проверка API

Получить список статей:

```bash
curl http://localhost:8080/articles
```

Получить статью с ID 1:

```bash
curl http://localhost:8080/articles/1
```

Создать статью:

```bash
curl -X POST http://localhost:8080/articles \
  -H "Content-Type: application/json" \
  -d '{"title":"Моя статья","content":"Текст статьи"}'
```

Удалить статью с ID 1:

```bash
curl -X DELETE http://localhost:8080/articles/1
```

## Хранение данных

Статьи хранятся в памяти приложения. После перезапуска сервера список возвращается к исходному состоянию.
